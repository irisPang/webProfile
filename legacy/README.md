# Iris 个人网站

这个文件夹是可以给人看的一层。原来的工作文件夹继续留着私人规划和未定稿。不要把那些文件夹整份复制进来，也不要一起上传。

## 这里现在有什么

- 她是谁：公开简介里已经写好的句子
- 做过什么：企业里的人工智能应用、Beyond the Tech、尚未发布的观照
- Beyond the Tech：栏目方向，不含嘉宾名单和制作进度
- 文字：一篇已经可以公开的个人文字

## 不要放进来的东西

- 个人节奏、财务、健康、考试和出行
- 嘉宾姓名、联络、跟进记录、采访大纲和成片路径
- 报价、客户和雇主名称
- 还没决定公开的灵感
- 电话、私人邮箱、住址、日程

判断标准：一个不认识 Iris 的人打开页面，会不会看到她没准备公开的生活或工作细节。会，就不要放。

## 默认不被搜索引擎收录

每个页面都写了 `noindex`，`robots.txt` 也要求爬虫不要抓取。这样即使文件夹被放到网上，搜索引擎也会被要求先不要收录。

决定公开传播时，再做这两件事：

1. 删掉每个 HTML 里的 `<meta name="robots" content="noindex, nofollow">`
2. 把 `robots.txt` 改成 `Allow: /`

## 加一篇新文字

1. 先确认这篇可以给不认识的人看。
2. 在这个文件夹里新写一页，只贴决定公开的正文。不要从工作笔记整篇复制。
3. 在 `writing.html` 加上链接。
4. 本地打开，再搜一遍电话、邮箱、公司、客户和嘉宾姓名。

## 本地查看

在这个文件夹里运行：

```bash
python3 -m http.server 8765
```

浏览器打开 <http://127.0.0.1:8765>。

上传时，只上传 `iris-personal-site` 这一个文件夹。
